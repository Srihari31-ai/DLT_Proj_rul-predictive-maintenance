Problem

Unexpected machine failures cause costly downtime and safety risks. Predictive maintenance uses sensor data to estimate the Remaining Useful Life (RUL) of equipment, so maintenance happens only when needed: not too early, not too late.

Objectives

  • Predict RUL of turbofan engines from multivariate sensor data
  • Build an LSTM deep learning model for time-series degradation
  • Compare it against a traditional baseline (Random Forest)

Dataset

NASA C-MAPSS FD001: 100 training engines (run to failure) and 100 test engines, with 21 sensors and 3 operating settings per cycle. 14 informative sensors were selected (the rest are constant). RUL is capped at 125 cycles.

Methodology

Raw sensor data→ RUL labelling (cap 125)→ Sensor selection + MinMax scaling→ Sliding window (30 cycles)→ LSTM (64, 32) + Dropout 0.2→ Dense → Predicted RUL

Results

ModelRMSE (lower is better)
Random Forest (baseline)17.16
LSTM13.09

The LSTM reduces RMSE by about 24% over the baseline. Predictions track the actual RUL closely near failure (low RUL), where accuracy matters most.

Conclusion and Future Work

The LSTM captures temporal degradation patterns and gives more accurate RUL estimates than Random Forest, enabling earlier and more reliable maintenance decisions.

Future work: GRU / attention models, extending to FD002-FD004 (multiple operating conditions), and real-time deployment.
